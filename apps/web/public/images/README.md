# Arquivos visuais esperados

Adicione fotografias reais e otimizadas nestes caminhos:

- `hero.jpg` — horizontal, preferencialmente 1920 × 1200
- `estrutura.jpg` — estrutura, estoque ou fábrica, 1400 × 1000
- `evento-anterior.jpg` — público ou atendimento, 1000 × 800
- `products/telhas.jpg`
- `products/tubos.jpg`
- `products/perfis.jpg`
- `products/vergalhoes.jpg`
- `products/chapas.jpg`
- `products/malhas.jpg`
- `products/laminados.jpg`
- `products/vigas.jpg`

Formatos recomendados: AVIF ou WebP. JPG também funciona no protótipo.
