# Arquivos visuais esperados

Adicione fotografias reais e otimizadas nestes caminhos:

- `hero.jpg` — horizontal, preferencialmente 1920 × 1080
- `estrutura.jpg` — estrutura, estoque ou fábrica, 1400 × 1050
- `evento-anterior.jpg` — público ou atendimento, 1200 × 900
- `products/telhas.jpg` — vertical, 900 × 1200
- `products/bobinas.jpg` — vertical, 900 × 1200
- `products/tubos.jpg` — vertical, 900 × 1200
- `products/perfis.jpg` — vertical, 900 × 1200

Formatos recomendados: AVIF ou WebP. JPG também é aceito.
